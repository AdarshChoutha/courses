# Courses

This repository contains projects and assignments completed as part of my learning journey through various online courses and training programs.  
It serves as a centralized place to organize, track, and showcase my hands-on development work.


## Repository Structure

The repository is organized using platform-based branch namespaces to keep course work clearly separated:

  `<platform-name>/<course-name>`

Each branch represents a specific course from a specific platform and contains the corresponding source code, exercises, and implementations.


## How to Explore

1. Switch to a branch based on the learning platform and course:
  ```bash
    git checkout <branch-name>
  ```

2. Review the project files, code structure, and implementations inside the selected branch.
