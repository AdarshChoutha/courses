# Graph Developer - Professional (Apollo GraphQL)

Welcome to the branch for the Apollo GraphQL course "**[Apollo GraphQL: Odyssey Voyage](https://www.apollographql.com/tutorials/certifications/apollo-graph-professional)**"! This course focuses on Apollo Federation 2 and building scalable, distributed GraphQL architectures using a federated supergraph approach.


## Overview

This branch contains the completed exercises and implementations from the Odyssey Voyage course series.  
The course emphasizes transitioning from a monolithic GraphQL API to a federated architecture, along with mastering schema design, observability, and production-ready GraphQL systems.


### Exercises and Learning Modules

  1. [**Voyage I: Federation from Day One**](https://www.apollographql.com/tutorials/voyage-part1)
      - **Description**:  Learn how to modularize a GraphQL backend using Apollo Federation and build a supergraph from scratch.
      - **Key Concepts Covered:**
        - Supergraph architecture (subgraphs and router)
        - Apollo Federation 2 fundamentals
        - Creating and publishing subgraph schemas
        - Using Rover CLI to interact with the supergraph
        - Configuring a local GraphOS Router
        - Creating and sharing entities across subgraphs

  2. [**Voyage II: Federating the Monolith**](https://www.apollographql.com/tutorials/voyage-part2)
      - **Description:**  Transform an existing monolithic GraphQL API into a federated supergraph incrementally.
      - **Key Concepts Covered:**
        - Splitting a monolith schema into subgraphs
        - Incremental migration to federation
        - Using the @override directive
        - Moving types and fields across subgraphs
        - Configuring authentication in a federated setup

  3. [**Voyage III: Federation in Production**](https://www.apollographql.com/tutorials/voyage-part3)
      - **Description:**  Prepare and manage a federated GraphQL system in production using GraphOS tools and CI/CD workflows.
      - **Key Concepts Covered:**
        - Graph variants for multiple environments
        - Schema checks and validation
        - CI/CD integration for subgraphs
        - Using GraphOS launches to debug issues
        - Operation checks and failure handling
        - Using @inaccessible for gradual schema evolution
        - Observability and graph performance insights


### Skills and Technologies Used

- **GraphQL** – Advanced API design
- **Apollo Federation 2** – Distributed GraphQL architecture
- **Apollo Gateway** – Query orchestration
- **Apollo Server** – Subgraph implementation
- **Node.js** – Backend runtime
- **JavaScript (ES6+)** – Modern development patterns
- **Rover CLI** – Schema checks and composition
- **Apollo Studio** – Monitoring and graph management
