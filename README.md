# Information Security (freeCodeCamp)

Welcome to the branch for the freeCodeCamp course "**[Information Security](https://www.freecodecamp.org/learn/information-security)**"!
This course focuses on the fundamentals of securing web applications, protecting sensitive data, and understanding basic penetration testing techniques.

## Overview

This branch contains excercises and projects completed as part of the freeCodeCamp Information Security certification.  
The work here demonstrates practical understanding of web security concepts, secure application development, and basic network security tools.

### Exercises and Learning Modules

   1. **Information Security with HelmetJS**
      - **Description**: Exercises focused on securing web applications using HelmetJS and other security best practices to protect sensitive data and mitigate common web vulnerabilities.
      - **Key Concepts Covered**:
        - HTTP security headers
        - Protecting user data
        - Web application security fundamentals

   2. **Python for Penetration Testing**
      - **Description**: Hands-on exercises using Python to understand the basics of penetration testing and network security.
      - **Key Concepts Covered**:
        - Network scanning techniques
        - TCP/IP communication
        - Security testing fundamentals


  ### Projects
  
   - [x] **[Stock Price Checker](./projects/stock-price-checker)**  
     A secure API-based application that retrieves stock price information while applying security best practices to protect requests and user data.

   - [x] **[Anonymous Message Board](./projects/anonymous-message-board)**  
    A message board application that allows anonymous posting while focusing on data protection, secure storage, and controlled access.

   - [x] **[Port Scanner](./projects/port-scanner)**  
    A network utility built to scan open ports on a target system, providing hands-on experience with basic reconnaissance techniques.

   - [x] **[SHA-1 Password Cracker](./projects/sha-1-password-cracker)**  
    A project demonstrating password hashing concepts and the importance of secure credential handling by working with SHA-1 hashes.

   - [x] **[Secure Real-Time Multiplayer Game](./projects/secure-real-time-multiplayer-game)**  
    A real-time multiplayer application emphasizing secure communication, data validation, and protection against common attack vectors.


### Skills and Technologies Used

- **JavaScript / Node.js** – Secure backend development
- **HelmetJS** – Enhancing web application security
- **Python** – Network tools and scripting
- **TCP/IP** – Networking fundamentals
- **Nmap** – Port scanning and reconnaissance
