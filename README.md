# Graph Developer - Associate (Apollo GraphQL)

Welcome to the branch for the Apollo GraphQL course "**[Apollo GraphQL: Odyssey Lift-Off](https://www.apollographql.com/tutorials/certifications/apollo-graph-associate)**"! This course introduces the fundamentals of GraphQL using Apollo Server, focusing on schema design, resolvers, and building a production-ready GraphQL API.


## Overview

This branch contains the completed exercises and implementations from the Odyssey Lift-Off course series.  
The course is structured into four parts, each building on the previous one to gradually introduce core GraphQL and Apollo concepts.


### Exercises and Learning Modules

  1. [**Odyssey Lift-Off Part 1**](./odyssey-lift-off-part1)
      - **Description**:  Introduction to GraphQL fundamentals, including schemas, types, and queries, using Apollo Server.
      - **Key Concepts Covered:**
        - GraphQL basics
        - Schema and type definitions
        - Apollo Server setup

  2. [**Odyssey Lift-Off Part 2**](./odyssey-lift-off-part2)
      - **Description:**  Expands the GraphQL API with resolvers and deeper schema relationships.
      - **Key Concepts Covered:**
        - Resolvers
        - Query execution flow
        - Connecting schema to data sources

  3. [**Odyssey Lift-Off Part 3**](./odyssey-lift-off-part3)
      - **Description:**  Introduces mutations and advanced resolver logic to handle data updates.
      - **Key Concepts Covered:**
        - Mutations
        - Input types
        - Server-side data handling

  4. [**Odyssey Lift-Off Part 4**](./odyssey-lift-off-part4)
      - **Description:**  Focuses on production-readiness, including best practices and API structure improvements.
      - **Key Concepts Covered:**
        - API organization
        - Performance and best practices
        - Preparing a GraphQL API for real-world usage


### Skills and Technologies Used

- **GraphQL** – API query language
- **Apollo Server** – GraphQL server implementation
- **Node.js** – Backend runtime
- **JavaScript (ES6+)** – Modern JavaScript syntax and patterns
- **API Design** – Schema-first development approach

  ```bash

  cd courses

  git checkout apollographql/graph-developer-associate
  ```

Follow any instructions provided within the individual project folders.
