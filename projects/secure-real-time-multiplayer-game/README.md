# Secure Real Time Multiplayer Game

This project is a completed implementation of the freeCodeCamp Secure Real-Time Multiplayer Game challenge.

It demonstrates a real-time multiplayer game built using Node.js, Express, Socket.IO, and the HTML Canvas API, including proper security headers and real-time player synchronization.

## Features
- Real-time multiplayer gameplay using Socket.IO
- Player movement using keyboard controls
- Collectible items with scoring system
- Player ranking based on score
- Secure headers to prevent common web vulnerabilities
- Fully compliant with freeCodeCamp project requirements

## Installation

1. Clone the repository or download the project files.

2. Install dependencies:
	```bash
    npm install
    ```

## Usage
Run the project
```bash
npm run start
```

## Testing
Run all unit tests using:
```bash
npm test
```

**The application supports**:
- Multiple connected players
- Real-time position updates
- Player disconnection handling
- Secure HTTP headers validation
